# Pipe Hitters

A browser run-and-gun prototype focused on smooth movement, aiming, and shooting. Block figures and a small test yard only — this is the core-mechanics pass.

Play: https://ma-name-is-jeff.github.io/pipe-hitters/

## Controls

### Desktop
- Click the game to capture the mouse
- **WASD** — move
- **Mouse** — aim
- **Left click** — shoot
- **Shift** — sprint
- **Space** — vault a low obstacle when you are next to one
- **C** or **Ctrl** — slide
- **R** — reload
- **Esc** — release the mouse

### Mobile
- **Left stick** — move
- **Right stick** — aim and fire
- **Vault / Slide** buttons

Ammo is shown in the lower right. Dummy targets flash, fall over when downed, and then stand back up.
